# Fleet selection and short part notes

User request: remove the answer-revealing card image crops and the top “Explore, match, discover” strip. Add a very short part history and fun fact in a right-hand sidebar on selection or dragging. Add different aircraft, including the Boeing 737, 787, Airbus A220 and a fighter.

The game now has text-only cards, a reserved desktop notes rail, and a compact dismissible mobile notes overlay. Notes contain one short history sentence and one short fact sentence, with NASA, FAA or Airbus reference links. In the definition round, notes appear only after a correct match so they cannot reveal the answer first.

The aircraft picker selects four playable aircraft with separate progress. Existing single-aircraft progress migrates to the 737. Aircraft-specific data supplies appropriate control names, available views, marker locations, dynamic match totals, completion reports, and resets scoped to the current aircraft. The fighter has no passenger cabin. All scenes are locally hosted responsive WebP images generated with built-in ImageGen; no runtime graphics library or external image host was added.

Verification includes full completion of every aircraft, independent saved progress, old-save migration, malformed state, mouse and touch input, accessible keyboard matching, reduced motion, image loading, text-only cards, short part notes and mobile layout. The view selector was made more compact and nearby callouts adjusted after a completion check found an occluded wingtip marker. Desktop and phone screenshots were inspected.
