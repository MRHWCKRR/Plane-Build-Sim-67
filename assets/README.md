# Artwork

Generated with the built-in ImageGen tool on 20 October 2026. These are AI-generated illustrative aviation assets, not photographs of a specific aircraft. The site uses raster WebP images, with an alpha channel preserved for the airplane sprite. No SVG artwork is used.

- `hero-800.webp`, `hero-1600.webp`: responsive versions of the blue-and-white airplane flying over clouds.
- `plane-640.webp`, `plane-960.webp`: responsive transparent airplane sprites for the scroll sequence.
- `favicon.png`: small raster crop of the generated plane.

## Hero prompt

Realistic white-and-cobalt-blue single-engine high-wing propeller airplane above white cumulus clouds in an azure sky. Front three-quarter view, airplane on the right with negative space on the left for page copy. Natural daylight, editorial aviation photography. No text, logos, or watermarks.

## Sprite prompt

Realistic white-and-cobalt-blue high-wing training airplane, entire aircraft visible, nose to the right. Clean photographic cutout with crisp wings, cockpit, and propeller. Truly transparent background. No clouds, ground, text, logos, or watermarks.
